# in3D.help — Kệ Modular Để Bàn In 3D Đáng Yêu ✿

Dự án giới thiệu và kinh doanh dòng sản phẩm kệ modular để bàn in 3D thương hiệu **BlueMoon's Studio**.

## 1. Về dự án
Website cung cấp thông tin chi tiết về các combo kệ pegboard lắp ghép thông minh, bo góc đáng yêu với tone màu pastel ấm áp. Người dùng có thể dễ dàng xem chi tiết cấu tạo sản phẩm, tham khảo bảng giá combo (Starter, Pro, Creator) và thực hiện liên hệ đặt hàng nhanh chóng qua Zalo.

## 2. Công nghệ sử dụng
- **Framework**: Astro (SSG)
- **Styling**: CSS thuần (Custom CSS)
- **Deployment**: Tự động deploy trên Cloudflare Pages qua GitHub integration.
